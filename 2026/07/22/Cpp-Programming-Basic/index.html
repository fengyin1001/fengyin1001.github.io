Introduction of Cpp/C++

什么是Cpp? Cpp与C++本质上是一种东西，只是念法不同，因此之后的讲述都以Cpp为准。

Cpp是一种高级编译语言。高级编译语言是高度抽象的编程语言，使用接近人类日常的自然语言和数学逻辑。

它依赖编译器在运行前将整段代码一次性翻译成机器码，生成计算机能直接执行的程序，从而屏蔽硬件细节、提升开发效率。

让我们开始我们的第一个Cpp程序吧！

#include <iostream>
这一行是导入系统库，该库封装了cpp的基础语法，是cpp官方推荐的库，因此后续都会使用这个库来讲解。
using namespace std;
这一行是为了方便以后函数前不需要写std::，倘若不加这句的话以后的函数或stl容器都需要加std::，例如std::cout<<1;。
int main(){}
这行是代表程序的主函数，意思就是所有需要执行的代码都要写在这里面。
cout<<"Hello World"<<endl;
cout这个函数代表的是输出，与printf的意思相同但底层执行不一样。
“Hello World”表示一个字符串的内容为Hello World。
endl的全名叫endline，就是换行的意思。

所以以上这整行就是将Hello World输出到控制台再换行。
return 0;
这行表示程序执行到这里的时候结束。

以上这些就是Cpp最基础的框架与语法结构，将这段代码亲手敲在编译器上就代表你正式入门Cpp了。
